# 命运之牌 1.0.7 调试预览版

包名：`com.example.cardsfate`；版本号：`1.0.7`（8）；架构：`arm64-v8a`。

## 本轮更新

- 78张牌竖立朝向用户环绕展示；默念结束后自动翻背并整齐叠放。
- 稳定松开后才能再次抽牌，三次独立点按抽出三张，避免一次动作重复出牌。
- 抽出的牌短距离抬起后，在牌堆上方横排，前后深度保持一致；引导面板上移，解读面板位于牌下方。
- 注视并捏合双指或指尖点按，沿垂直中轴翻牌；图案统一正向，正逆位仍以50%概率产生并用于标识和解读。
- 面板固定于仪式开始时的正前方，转头不会带着面板移动。
- 历史记录仅在开始页开放，顶部固定返回按钮支持详情→列表→开始页。
- 移除蜡烛实例；加入3个水晶、2个星盘、48个符文，增加后方氛围。
- 三张牌逐张解读结束后直接显示“再来一次”，不播放或显示综合解读；记录仍自动保存，保留最近10次。
- 改进空间几何比对、工作区选择和恢复逻辑，保留真实环境避让检查。

## 下载与安装

[下载调试 APK](https://github.com/DDDCC5/CardsOfFate/releases/download/v1.0.7-debug/cards-fate-1.0.7-debug.apk)。安装包已包含牌面、模型、界面、旁白和音效，无需配置生成模型的密钥。

需要兼容的PICO Spatial运行环境；普通Android手机不能提供对应的空间服务。源码使用PICO Spatial SDK BOM 6.1.9、Kotlin和SpatialUI Compose。

下载后可用同一Release中的`SHA256SUMS-1.0.7.txt`校验文件。此版本采用调试签名。

## 验证范围

构建、60项单元测试、素材打包检查及独立UI风格检查通过。实机已观察到三次独立抽牌、三张牌逐张翻开及解读过程中的有效空间检查；截图核对了前景横排和正向牌面。本轮已收到用户试用后的发布指示。

这是调试预览版。更多设备/房间、长时间性能和界面易用性仍需持续验证。通用静态脚本对既有Mixed Stage配置及SDK通配导入仍有识别报错，未标记为全通过；详见[README](../../README.md)和[验证记录](1.0.7-verification.json)。
