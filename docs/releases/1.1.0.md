# 命运之牌 1.1.0 · 近身塔罗仪式调试版

2026-11-19，包名com.example.cardsfate，versionCode 9，arm64-v8a；仍为调试签名。SDK维持6.1.9。

## 本轮变化

- 自动叠牌后展开近身牌扇，每组13张、共6组；可左右轻扫或用上一组/下一组浏览78张。
- 捏住牌后移动到过去/现在/未来空位，按卡牌真实视觉中心决定是否确认。轻点牌背仍可放到下一空位；不能重复选择或占用同一牌位。
- 捏住时以真实手部姿态差值驱动，不加磁吸、自动对齐或轨迹修正。未揭示牌只显示背面，不能通过拿起偷看。
- 短捏/轻点翻牌，长捏拿起查看。揭示后的牌支持平移与旋转；松手沿已检查的路径归位。抓持释放不会同时触发翻牌。
- 已揭示牌可点选回看下方解读，不重播旁白、不重写历史、不跳过下一张的音频完成条件。
- 捏合开始立即锁定翻组；生命周期暂停、丢手、过期数据与安全暂停取消临时握持，避免恢复后确认旧动作。
- 新增24个模型实例的可复用反馈池：拖尾光点、合法落位光环、翻牌符文、三牌关系线与空位标记。关系线配合原有本地关键词，不显示综合总结。
- 抽牌、翻牌与退回音效使用3个可复用ObjectAudioComponent发声实体，随卡牌位置变化；不可用时回退现有音效。旁白继续使用原混响系统。
- 原有世界固定面板、三牌下方解读、开始页历史与返回、无蜡烛、系统语言分别显示等行为保留。
