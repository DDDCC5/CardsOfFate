# 1.1.2 翻牌交互与牌位标签修复

日期：2026-11-26。包名：`com.example.cardsfate`，versionCode：11。

解读阶段原先沿用抽牌的点击/抓持分类，捏合稍慢就会归为抓持，随后被固定牌位规则取消。现在解读阶段使用独立的捏合按下确认；持续捏合不会重复触发，释放后才能再次确认。指尖点按增加连续采样的穿面检测，减少快速触碰漏判。眼动未命中时可使用现有手指射线。已揭示牌仍可回看，正在或已经解读的牌保持固定，逐张旁白结束后才能翻开下一张。

过去、现在、未来标签锚点从牌中心下方7厘米调整至13厘米。待抽牌扇下移8厘米，关联线同步下移，给标签留出空间。空间避让检查继续使用调整后的牌扇位置。

验证：89项单元测试通过，0失败、0错误、0跳过；debug构建、素材打包、自定义启动图标像素核对和UI风格检查通过。1.1.2已覆盖安装并启动于真实PICO，安装查询确认版本11。实机日志已记录抽满三张后第一张成功翻开；完整三张翻牌及标签视觉效果仍待用户验收，未将启动成功作为交互通过的证据。

公开发布：[v1.1.2-debug](https://github.com/DDDCC5/CardsOfFate/releases/tag/v1.1.2-debug)。本地APK：`delivery/debug/cards-fate-1.1.2-debug.apk`。
