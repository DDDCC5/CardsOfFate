## 体验与实现

- 78张牌缩小15%后竖立朝向用户环绕展示；默念结束后自动翻背整齐叠放。点按牌堆三次，每次抽出一张，再继续过去/现在/未来解读。
- 使用官方手部关节、眼动及头部追踪；眼动不可用时支持手指指向与捏合。
- 未揭示牌面节点禁用；注视捏合或指尖点按后沿垂直中轴翻牌。按用户确认，图案统一正向显示，正逆位仍以50%概率产生并用于标识和解读。
- 中文/英文独立牌面、文案和逐张混响旁白；保存最近10次记录。历史入口只在开始页，逐张解读结束后直接显示再来一次，不显示或播放综合解读。
- 3个水晶、2个旋转星盘和48个符文，增加后方布景；不再实例化蜡烛。自定义暗色金线界面和分层启动动画。
- 预留大模型解读、其他塔罗体系和付费接口；当前版本无在线生成或购买流程。

## 验证范围与运行前提

1.0.7 构建、60项单元测试、素材打包检查和独立UI风格检查通过。已在PICO头显安装运行，实机记录确认三次独立抽牌及三张牌逐张翻开，空间检查在本轮解读过程中保持通过；截图已核对三张牌前景横排和正向牌面。发布信息与验证范围见[验证记录](docs/releases/1.0.7-verification.json)。

牌堆实体厚度与间距减半，候选正前方距离约45厘米。三张阅读牌以实际牌堆为锚点，在上方12厘米、相同前后深度横排，解读面板位于这排牌下方。抽牌先平放抬起再旋转横移；抽牌和翻牌均要求稳定释放后再点击，避免触碰边界抖动重复触发。

历史页的返回按钮固定在顶部，不随记录列表或详情正文滚出视野；详情返回列表，列表返回开始页。

面板采用固定空间位置：开始仪式时确定正前方，转头不带动面板；解读面板固定在三张牌下方。牌堆在默念结束时按当前头显视线选择居中偏下的候选位置，不继承环绕避让的上移量或侧移。已知平面与实际飞行路径仍需检查。

当前设备已提供有效系统平面，启动布局检查已通过。应用区分空间数据不可用与位置避让未通过，不新增扫描引导，也不跳过已知真实几何检查。

更多设备和房间环境下的交互阈值、长时间性能及逐屏视觉一致性仍需继续验证。避让只覆盖系统已知几何；公开SDK接口不能强制切换系统输入模式，手柄提示基于追踪状态及姿态活动。

通用静态校验脚本尚未全通过：它要求现有Mixed Stage的immersion字段为0，并将SDK通配导入判为格式错误。官方SDK说明这些immersion字段只作用于Progressive样式。正式构建和独立风格检查已通过，未将通用校验报告标记为通过。

所有解读仅供娱乐和自我思考参考。

## 构建

- Kotlin + SpatialUI Compose + PICO Spatial SDK BOM 6.1.9。
- JDK21、Android SDK35、arm64-v8a。需要 PICO Spatial 运行环境；普通 Android 手机不具备对应空间服务。
- 配置 `ANDROID_HOME` 或本地 `local.properties` 的 `sdk.dir` 后运行：

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
python3 tools/verify_runtime_package.py
```

APK输出：`app/build/outputs/apk/debug/app-debug.apk`。运行素材已包含，无需模型生成服务或API密钥。源码中有两个约78MB牌库文件，完整克隆会下载约400MB素材。

## 目录

- `app/src/main/java/com/example/cardsfate/`：空间场景、追踪、领域状态、音频、仓库和界面。
- `app/src/main/assets/`：9个GLB文件、1262段旁白、14个音效、文本和许可。
- `app/src/test/`：占卜状态机、手势分类、历史裁剪、语言及音频回调测试。
- `docs/submission/`：按Vibe Lab字段整理的投稿文案与素材说明。

本仓库仅发布应用工程与运行所需素材；不包含本机配置、SDK二进制、插件实现、生产虚拟环境和真实房间截图。第三方来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。公开代码未额外指定统一开源许可证；第三方内容各自遵循其原始许可。
